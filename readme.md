# C++ Projects Sandbox

My personal workspace for C++ projects and experiments.

## ⚙️ Tech Stack

Language: C++ (basic to modern, varies per project)
Compiler: GCC, Clang, or MSVC
Build System: Direct compilation (single-file) or CMake (multi-file)

## 🛠️ How to Compile & Run

Each project is a standalone directory. Most are single-file — just compile and run:

```bash

g++ main.cpp -o main
./main
